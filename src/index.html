Beyond Explicit Corrections

Implicit behavioral signal learning in LLM agents

The problem

Most personalization research assumes users explicitly correct an agent. Real users rarely do. They rephrase, ignore answers, get frustrated, or simply leave.

What I built

I'm extending MultiSessionCollab so agents learn from those implicit signals, and designing BSEM, a Behavioral Signal Extraction Module that detects them and turns them into structured preference hypotheses for memory-equipped agents.

Results

  • Benchmarking agent adaptation across GPT-4o and Llama-3.3-70B
  • Signals modeled: rephrasing, ignoring, frustration, abandonment

Note-Worthy

Personalized LLMs for medical document rewriting

The problem

Clinical documents are hard for patients to read, and a single simplified version doesn't fit every reader.

What I built

A preference elicitation pipeline that captures reader signals such as terminology comfort, tone, and detail level, then drives personalized LLM rewrites of clinical documents.

Results

  • Ran a within-subjects user study comparing original, generically simplified, and personalized rewrites
  • Personalized rewrites scored higher on comprehension and satisfaction than generic simplification

Depression Detection

Machine learning and NLP, published with IEEE

The problem

Signs of depression often appear in how people write, but that text is unstructured and noisy.

What I built

A classification pipeline that turns raw text into features with tokenization, TF-IDF, and word embeddings, and handles noise, missing values, and imbalanced classes.

Results

  • Published as an IEEE paper
  • Benchmarked several classifiers on accuracy, precision, recall, and F1 score

Flight Delay Prediction

Python, XGBoost, data engineering

The problem

A single late flight can delay every later flight that aircraft flies that day.

What I built

I processed 2.7M+ raw airline records and engineered lag-based features to model how delays propagate, then built an XGBoost classifier with target encoding and class weighting for extreme class imbalance.

Results

  • Reached 0.70 weighted F1
  • Outperformed linear and bagging baselines
